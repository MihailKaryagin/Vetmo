# Показ vetmo: от поиска игрока до готового состава

## Перед показом

Из корня проекта:

```powershell
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe manage.py seed_demo --refresh
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe manage.py runserver
```

`--refresh` обновляет связанные записи наполнения и сдвигает расписание относительно дня запуска. Выполнять перед показом, а не между действиями пользователя: команда возвращает подготовленным составам и заявкам исходные значения.

Созданные командой пароли хранятся локально в `.local/demo_accounts.json`. Не показывайте этот файл на проекторе. Для демонстрации нового пользователя удобно зарегистрировать отдельный аккаунт через сайт. Для административной части используйте свой аккаунт Django admin.

## Сценарий на 5–7 минут

1. **Главная `/`**. Показать ближайшую встречу, свободные места/очередь, объявления, последний разбор и следующую серию турнира. Всё берётся из базы.
2. **Игроки `/players`**. Отфильтровать игроков по роли, MMR, цели и времени. Открыть `sayro`: пул с изображениями героев, биография, достижения, объявления, матчи и турнирные составы.
3. **Пати**. Из профиля перейти в объявление. Отправить отклик от нового аккаунта с ролью и контактом. После отправки появится подтверждение; капитан увидит отклик в своём объявлении и уведомление в кабинете.
4. **События `/events`**. Записаться на разбор реплея. В кабинете в блоке «Мои события» проверить дату и статус. У пятничного микса основной состав заполнен: запись попадёт в очередь. При отмене основной записи самый ранний ожидающий получит место.
5. **Матчи `/matches`**. Открыть разбор из профиля. Показать состав, ссылки на игроков и турнир; перейти к сетке. В «Осеннем капе» есть победитель, в «Кубке буднего вечера» — предстоящий финал, в «Вечернем капе» — регистрация без преждевременных результатов.
6. **Админка `/admin/`** в отдельном браузере. Открыть регистрации событий и проверить новую запись, затем показать заявку в гильдию, редактирование публикации и поля связей у разбора матча. Принятие участника в пати выполняется капитаном на сайте.
7. **Поддержка**. Написать посетителем вопрос в виджет, ответить в `/admin/main/supportconversation/`. Ответ появится в виджете при очередном обновлении.

## Планирование и статистика

- В кабинете заполнить дни, интервал и часовой пояс. На странице поиска пати появятся объяснения совпадений по свободной позиции, MMR и времени. Для сравнения времени оба игрока должны заполнить структурированное расписание.
- В пати показать пять слотов. После принятия четырёх игроков капитан назначает время, участники получают уведомления и подтверждают участие. Кнопка календаря скачивает `.ics`.
- Из списка матчей открыть «Полный разбор и статистика». Пользователь с правом изменения разборов может указать реальный ID Dota-матча и загрузить OpenDota. У подготовленных историй ID не выдумываются, поэтому статистика появится только после явной привязки.
- На телефоне открыть «Меню», перейти в раздел, проверить закрытие по Escape и доступность кабинета.

## Быстрая проверка перед выступлением

- На ширине телефона открыть фильтры, форму события и поддержку.
- В форме события отправить пустой контакт: видна ошибка, введённый ник сохраняется.
- В фильтрах игроков задать MMR «от» больше «до»: видна ошибка диапазона.
- Перейти по цепочке «профиль → разбор → турнир → профиль».
- Проверить подключение к интернету: изображения героев загружаются из CDN Valve. Подписи героев остаются доступны и без изображения.

Источники изображений: CDN Valve `cdn.steamstatic.com/apps/dota2/images/dota_react/heroes/`; соответствие названий — открытый каталог [OpenDota dotaconstants](https://github.com/odota/dotaconstants/blob/master/build/heroes.json).
